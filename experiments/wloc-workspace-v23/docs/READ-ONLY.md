# 独立 GET 读取入口

浏览器的“读取已存位置”使用 `GET https://wloc-settings.invalid/wloc-read/v1/`。请求没有正文、坐标或查询参数；模块只为这个精确 URL 声明一条 requires-body=0 规则，不与原 v2 控制规则重叠。

该入口只读取正式值和备份是否可识别，返回与旧 POST query 相同的协议、状态、目标和 canRestore。不会创建备份、写入正式值、恢复或清除数据，也不返回备份原始内容。请求使用 no-store、omit credentials、no-referrer 和拒绝重定向；响应仍有 no-store、nosniff、无 CORS 放行。启用条件、Origin 和 Fetch-Site 限制与原 API 相同。原生调用许可仍不是身份认证。

读取路径只接受 GET，拒绝 POST/HEAD/OPTIONS 等方法；多余路径、查询参数与别名也不接受。原 `/wloc-control/v2/query` POST 读取继续可用，快捷指令不需为此改动。保存、清除和恢复没有新增 GET 入口，也没有失败后自动改用另一种方法的行为。

本版 182 项本地回归已通过，包含正文访问陷阱、存储写入陷阱、跨源请求、坏值和备份、读取抛错、路由互斥、旧 POST 兼容和结果未知保护。18 项真实本地 HTTP 对照分别运行原 POST、有意去除正文的 POST、独立 GET：在故意注入的 POST 回显请求体或断开连接情形下，GET 可以继续读；当所有方法的响应都被替换时，GET 也拒绝结果。全部对照只读且无存储写入。

这些故障是本地构造，不代表已查明手机行为。该路径在 v2.2 已收到用户真机读取成功反馈，本版保持其代码和模块规则不变；不能证明 POST 保存故障或系统定位已修复。读取成功只能确认当次读到的状态。之前的保存若未知，不要用再次保存、清除或恢复代替核对。
